# Report Q&A Notes

This folder stores question-and-answer notes that may be reused in the final
report, paper draft, thesis text, or presentation narrative.

Use this folder for explanations that clarify:

- active-learning workflow choices;
- ML model architecture and training logic;
- exact BdG oracle and quality-gate semantics;
- phase-boundary interpretation;
- numerical caveats and unresolved scientific questions.

Recommended file naming:

```text
YYYYMMDD_topic.md
```

Recommended entry format:

```md
## Question

User-facing question or concern.

## Short Answer

Concise answer suitable for report integration.

## Technical Notes

Implementation details, equations, assumptions, caveats, and file references.

## Report Use

Where this explanation should appear in the final report.
```

Keep entries factual and traceable. Do not overwrite exact definitions from
`MODEL_SPEC.md`, numerical rules from `docs/NUMERICS_SPEC.md`, or decisions
from `docs/DECISIONS.md`.
