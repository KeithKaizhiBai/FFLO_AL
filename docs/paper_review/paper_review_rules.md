# 论文阅读检查规则

建立日期：2026-09-12。适用：物理与计算方法论文。判断依据是当轮指定的公开稿件；不把内部解释补进读者理解，不以总分代替具体诊断。

## 使用顺序

1. 锁定用户指定 PDF，记录文件名、页数和内容校验值。先读正文、图及图注，再读补充材料；此时不读旧评审和内部完成报告。
2. 保留约 200–300 字独立理解，以及“正文可知／需补充材料／仍不确定”的记录。
3. 逐项应用下表。文字检查用 T，最终页面视觉检查用 V，需要作者或额外证据用 A。每条可同时使用几种方法。
4. 第二遍仅查确有需要的源文件、提供的批准记录和配置，以区分表达不足、实施细节缺失、版本不符和科学问题。保留第一遍障碍。
5. 每项发现记录：编号、类别、严重程度、位置（文件与 PDF 页码、图表或段落）、原文/现象、影响、建议、科学含义是否变化、处理责任、复查办法、证据性质。
6. 四种严重程度：**必须修改**（主要误读、关键方法不明、不可读、错版或重要引用失配）；**建议修改**（连贯性或表达明显受损）；**可选改善**（风格）；**需要作者判断**（物理、证据、范围或版本待确认）。证据标为直接观察、推断、官方规范核对、未确认。

## 视觉检查记录办法

每图记录整页位置、页面物理尺寸、插入尺寸（能测则测）、正常阅读尺度判断与放大观察。嵌入栅格图不能用 PDF 周围正文的字号冒充图内字号；无法精确测量时明确为定性判断。图表若跨页须检查续页。提取乱码先回看页面，不直接报排版错误。必要时灰度辅助，不修改原图。

## 防止过度审稿与复查

提交前逐一自检：Supplement 已充分说明的超参数不再要求主文重复；数字真实不代表叙事充分；放大可读不等于成稿可读；正确批准图无需重绘；离散证据须按实际声称贡献判断；不按数字数量或段落字数机械评判；无证据的解释不能靠润色强化；没有旧稿对照不能声称旧问题已关闭。

下一轮沿用编号，记录已解决/部分解决/未解决/需作者判断，检查改动引入的新误读。不为持续迭代增加风格要求。仅发现规则本身误判时修订并记原因。
