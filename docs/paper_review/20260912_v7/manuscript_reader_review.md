# 本轮独立阅读评审

日期：2026-09-12。规则：[论文阅读检查规则](../paper_review_rules.md)。范围：指定的单栏正文 8 页、Supplement 12 页；不审双栏稿，不作新计算、新颖性调查或自由能正确性审查。

## 第一遍记录（查看内部资料前保留）

文章研究一维含自旋轨道耦合与交错磁性劈裂的超导模型，关注有限配对动量下的热力学相区及其中可定义的拓扑类别。计算在配对幅度和动量上寻找数值目标的最低点，先区分正常态、均匀超导与 FFLO，再对可靠且有隙的 FFLO 作全布里渊区能隙与 Pfaffian 检查。主动学习用回归和分类集成安排下一批计算，物理标签仍来自 BdG 求解。二维结果显示窄的均匀超导带、广泛的 FFLO 区及弯曲外缘；拓扑类别在温度和劈裂方向上分离。加入化学势后，采样支持发生重组。二维位置计数显示节省，但不等于实测加速；三维结论限于离散样本和窄化学势窗口，不能推作完整连续相面。

- **正文直接可知**：研究动机、热力学与拓扑的先后关系、AL 只安排求解位置、二维主要形状、位置占比与运行时间的区别、三维证据范围。
- **必须翻 Supplement**：固定耦合及二维化学势、Nambu 表示与完整目标、幅度/动量阈值、网络与训练、分阶段选点、请求和保留计数、重构参数。
- **仍不能确定**：主文未明示配对空间 Ansatz；oracle 的 enclosure、近简并与近零配对判据如何实施；能隙通过阈值与细化；各阶段停止条件如何对应；Fig. 4(c) 只见热力学配色却支撑逐切片拓扑叙述；Fig. 3(b) 的曲线、括区与 gap 数据如何对应；没有公开科学复现入口或本轮批准图记录。

这份第一遍判断不因后续读到源文件而追溯改成“稿件已经讲清楚”。

## 结论和最重要的五件事

**文章是否读得顺：基本可以，但需要局部修改。** 引言从有限动量配对到交错磁性、拓扑与计算成本的逻辑成立；Results 已经解释相区随参数的变化，不能把这稿概括为纯项目报告。问题是公开结果与内部记录用语混杂，Discussion 的末段突然转向未展示的 learned acquisition/world model；同时浮动图打断了多处连续句子。

**方法是否足以理解和实施：理解框架基本可以，独立实施需要修改。** 网络、训练和主要选点公式已有相当细节；不应要求把它们搬回正文。但可靠性判据、能隙通过标准、部分三维选点顺序、阶段停止方式仍需补全。下面的“说明清楚”仅属方法 A 层；有限源文件核对属 B 层；没有验证物理正确性或端到端复现 C 层。

**图是否在成稿中真正可读：需要修改。** 所有 4 张主图、5 张补图和 7 张表均完成整页及放大检查，并结合 PDF 实际插入尺寸判断。主图的大面板可辨，但 Fig. 3/4 的次面板与部分图例过小；Fig. 4(c) 还有不能仅靠放大解决的编码缺口。S1–S4 和各表总体可读，S5 的文字拥挤需修。

优先处理：

1. **R01：Fig. 4(c) 的热力学配色不能验证逐切片的拓扑描述。** 需让文字与实际显示的证据对应。
2. **R04、R05：补全真正决定求解返回和采样次序的步骤。** 不是再增加一张网络超参数表。
3. **R08、R09：修复主图细字、遮挡及补充材料断句式浮动。** 增大整图仍不足以解决内部布局。
4. **R12：S5 历史统计与主文 FFLO-only 拓扑范围不一致。** 必须明确两个统计对象，不可静默改数据。
5. **R02：把“观察到异号标签”与“已验证连续闭隙再开隙过程”分开。** 这一项需要作者判断现有证据能支持哪种表述。
