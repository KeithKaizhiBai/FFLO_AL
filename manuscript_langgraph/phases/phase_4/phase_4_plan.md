# Phase 4 plan — scientific and visual validation

## Audit

Compare candidate metadata against authoritative hashes, exact sample counts,
configured convergence decisions, sensitivity values, and strict Stage IV
non-convergence records.

## Plan

1. Validate all candidate formats and source manifests.
2. Check frozen hashes and key counts.
3. Render the approval-package PDF and inspect every page.
4. Record visual QA separately from scientific approval.

## Critique

A technically valid file is not automatically scientifically valid, and a
scientifically traceable candidate is not automatically human-approved.

## Non-changes

Validation does not pass `GATE_FIGURE_APPROVAL`.
