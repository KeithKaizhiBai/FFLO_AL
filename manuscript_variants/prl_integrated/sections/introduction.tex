\section{Introduction}
The computational problem considered here is to map superconducting states when the equilibrium condensate may select both a finite pairing amplitude and a finite center-of-mass momentum. In the present altermagnetic BdG model, thermodynamic competition in $(\Delta,q)$ must be resolved together with numerical reliability and, inside the trusted gapped FFLO sector, a $\mathbb Z_2$ topology diagnosis. Exhaustive sampling becomes increasingly costly when each parameter point requires a free-energy landscape, branch refinement, and spectral checks, especially after the domain is extended beyond two coordinates. A data-driven scheduler can focus exact calls, but it would compromise the physical interpretation if surrogate predictions were promoted to final phase or topology labels. We therefore separate an exact BdG authority from reliability-aware active learning: the oracle determines accepted observations, whereas an ensemble acquisition rule selects only the next micro-batch. The resulting evidence chain comprises an audited two-dimensional thermodynamic reconstruction, a topology-resolved cFFLO/tFFLO result with an explicit sensitivity test, and a higher-dimensional extension whose strict topology closure remains incomplete. The main text first defines this division of labor, then follows the thermodynamic, topology-resolved, and three-dimensional results before closing with the limits of learned acquisition and a bounded world-model outlook.
