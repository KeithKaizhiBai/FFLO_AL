# Physics-first Introduction argument map

1. **Finite-momentum pairing:** establish the FF/LO thermodynamic problem.
2. **Altermagnetic opportunity:** explain compensated momentum-dependent spin splitting and cite only model-level precedents.
3. **Topology:** separate thermodynamic acceptance from the gapped class-D/Pfaffian diagnosis.
4. **Computational bottleneck:** explain why exact BdG phase mapping becomes expensive and why active learning is a scheduler.
5. **Contribution:** state the audited 2D, topology-resolved, and caveated 3D results without unsupported novelty or closure claims.

No paragraph begins with the project-specific phrase “the computational problem considered here.” External background precedes the project question, and every external claim is cited.
