# MODEL_SPEC.md

## 1. Project Goal

This project studies the finite-temperature phase diagram of a one-dimensional
altermagnetic FFLO topological superconductor. The numerical goal is not only to
produce a dense phase diagram, but also to identify phase boundaries accurately
with controlled use of expensive BdG calculations on GPUs.

The workflow has two coupled parts:

1. High-performance exact phase-diagram calculation.
   This provides physically reliable BdG data on a prescribed grid of
   temperature and altermagnetic coupling.

2. Active-learning-assisted phase-boundary refinement.
   A surrogate model learns from the exact data and chooses additional exact
   calculations concentrated near uncertain or rapidly varying boundaries.

The active-learning model is a scheduler for exact calculations. It is not a
replacement for the BdG solver.

## 2. Physical Model

The mean-field BdG Hamiltonian in momentum space is

$$
\begin{aligned}
    \mathcal{H}_{\mathrm{BdG}}
    &= \frac{1}{2} \sum_k
       \Psi_k^\dagger H_{\mathrm{BdG}}(k) \Psi_k
       + \frac{N}{U} |\Delta_q|^2, \\
    H_{\mathrm{BdG}}(k)
    &=
    \begin{pmatrix}
        h(k+q/2)-\mu
        & \Delta_q \\
        \Delta_q^*
        & -\sigma_y h^T(-k+q/2)\sigma_y+\mu
    \end{pmatrix}.
\end{aligned}
$$

The normal-state Hamiltonian is

$$
h(k)=\xi(k)+\mathbf{d}(k)\cdot\boldsymbol{\sigma},
$$

with

$$
\xi(k)=t\cos k,\qquad
\mathbf{d}(k)=
\left(0,\lambda_y \sin k,\lambda_z \sin k + J_A \cos k\right).
$$

The FFLO Nambu spinor convention is

$$
\Psi_k =
\left(
c_{k+q/2,\uparrow},
c_{k+q/2,\downarrow},
c^\dagger_{-k+q/2,\uparrow},
c^\dagger_{-k+q/2,\downarrow}
\right)^T.
$$

Symbols:

- \(t\): nearest-neighbor hopping amplitude.
- \(\lambda_y,\lambda_z\): spin-orbit coupling strengths.
- \(J_A\): altermagnetic exchange coupling.
- \(\mu\): chemical potential.
- \(U\): pairing interaction.
- \(\Delta_q\): superconducting order parameter at pairing momentum \(q\).
- \(q\): FFLO pairing momentum.
- \(k\): crystal momentum along the chain.
- \(N\): number of lattice sites or momentum points used in the discretization.
- \(T\): temperature, reported as \(k_B T/t\).

## 3. Observables and Labels

For every thermodynamic point

$$
x = (k_B T/t,\; J_A/t),
$$

the exact solver should return

$$
y =
\left(
\Delta_{\mathrm{opt}},
q_{\mathrm{opt}},
\eta,
I_c^+,
I_c^-
\right).
$$

Here \(\Delta_{\mathrm{opt}}\) and \(q_{\mathrm{opt}}\) minimize the free
energy, \(I_c^\pm\) are positive and negative critical currents, and \(\eta\)
is the superconducting diode efficiency.

The first-stage phase labels are

```text
normal:
    Delta_opt < DELTA_EPS

uniform_SC:
    Delta_opt >= DELTA_EPS and abs(q_opt) < Q_EPS

FFLO:
    Delta_opt >= DELTA_EPS and abs(q_opt) >= Q_EPS
```

Additional diagnostic labels are

```text
eta_pos:
    eta > 0

eta_neg:
    eta < 0

eta_zero:
    abs(eta) close to 0

strong_diode:
    abs(eta) > ETA_STRONG
```

Default thresholds should be conservative:

```text
DELTA_EPS = 1e-3
Q_EPS = 1e-2
ETA_STRONG = 0.5
BOUNDARY_MARGIN = 0.08
```

Topological labels such as trivial FFLO, topological FFLO, and edge-mode
presence are a second milestone unless a robust invariant is already exposed by
the existing solver. They should not block the phase-boundary active-learning
workflow.

## 4. Exact High-Performance Phase-Diagram Pipeline

The exact phase diagram is generated by a CUDA BdG calculation. The current
warm-start dataset is

```text
eta_phase_diagram_nkt138_nja156_nd400_nq400_nk800_kc8_jc8_dc4_qc100_kk200_eb10000_fp64_libcusolver_cfg422bd68ce6/
eta_phase_diagram_nkt138_nja156_nd400_nq400_nk800_kc8_jc8_dc4_qc100_kk200_eb10000_fp64_libcusolver_cfg422bd68ce6.npz
```

Expected arrays:

```text
kT_vec              shape (n_kt,)
JA_vec              shape (n_ja,)
q_vec               shape (n_q,)
eta_matrix          shape (n_ja, n_kt)
q_opt_matrix        shape (n_ja, n_kt)
delta_opt_matrix    shape (n_ja, n_kt)
ic_plus_matrix      shape (n_ja, n_kt)
ic_minus_matrix     shape (n_ja, n_kt)
delta0              scalar
```

Matrix convention:

```text
row = JA index
col = kT index
```

The exact pipeline is

```text
1. Choose a physical parameter grid in (kT, JA).
2. For each point, construct the BdG Hamiltonian.
3. For each candidate q, minimize the free energy over Delta.
4. Select q_opt and Delta_opt from the global free-energy minimum.
5. Compute current response and critical currents I_c^+, I_c^-.
6. Compute eta from the critical-current asymmetry.
7. Assign phase and diagnostic labels.
8. Save npz/csv outputs with full numerical metadata.
9. Plot eta, phase, q_opt, Delta_opt, and boundary diagnostics.
```

The exact phase diagram provides the warm-start data for active learning. It also remains the reference used to validate the surrogate model.

## 5. Adaptive Treatment of q

The FFLO momentum \(q_{\mathrm{opt}}\) is not fixed-scale across the whole phase diagram. Physically, increasing \(J_A\) pushes the preferred FFLO momentum to larger values. In particular, for \(J_A/t \gtrsim 1.2\), \(q_{\mathrm{opt}}\) can increase rapidly, so the original fixed \(q\) window may no longer contain the true free-energy minimum.

The solver and active-learning loop must therefore treat the \(q\)-range as an adaptive numerical object, not a permanent constant.

### 5.1 q-Window Validity Checks

Every exact evaluation must record whether the selected optimum is near the
edge of the scanned \(q\)-grid:

```text
q_edge_hit =
    abs(q_opt - q_min) < q_edge_margin
    or abs(q_opt - q_max) < q_edge_margin
```

If `q_edge_hit = true`, the result is not trustworthy as a final exact label.
It should be marked as requiring q-window expansion.

Recommended metadata per exact point:

```text
kT
JA
q_min
q_max
n_q
q_opt
q_edge_hit
q_refinement_level
```

### 5.2 q-Window Expansion Rule

For a point whose optimum touches the \(q\)-boundary, rerun the exact solver
with an expanded \(q\)-window before appending the point to the trusted dataset.

Example rule:

```text
if q_edge_hit:
    q_center = q_opt
    q_half_width_new = max(1.5 * q_half_width_old, q_half_width_old + q_step * 50)
    rebuild q_vec around q_center or extend in the hit direction
    rerun free-energy minimization
```

This expansion should repeat until one of the following is true:

```text
1. q_opt is inside the q-window by at least q_edge_margin.
2. q_window reaches a physically imposed maximum.
3. the solver reports a clear failure state.
```

The active-learning model must not treat edge-hit points as clean training
targets. They should either be corrected by rerunning with a wider \(q\)-window
or included with a low-confidence flag.

### 5.3 q Resolution Refinement

After the broad \(q\)-window contains the minimum, the solver should optionally
perform a local refinement around the coarse \(q_{\mathrm{opt}}\):

```text
1. Coarse scan over the full q-window.
2. Locate the best q cell.
3. Rescan a narrower local q-window around the best cell with finer q_step.
4. Use the refined q_opt for final observables.
```

This is especially important near the uniform-SC/FFLO boundary where
\(|q_{\mathrm{opt}}|\) is close to `Q_EPS`.

## 6. Adaptive Treatment of Delta

The superconducting order parameter \(\Delta_{\mathrm{opt}}\) controls the normal/SC boundary. Near this transition, a coarse \(\Delta\)-grid can shift the
apparent boundary because the free-energy minimum is shallow.

The solver must therefore use adaptive \(\Delta\)-refinement near phase
boundaries.

### 6.1 Delta Boundary Detection

A point is close to the normal/SC boundary if any of the following holds:

```text
abs(Delta_opt - DELTA_EPS) < delta_boundary_margin
large local gradient of Delta_opt in (kT, JA)
neighboring points change between normal and superconducting labels
free-energy difference between Delta = 0 and Delta_opt is small
```

These points should be assigned high acquisition priority and, when evaluated
exactly, should use refined \(\Delta\)-sampling.

### 6.2 Multi-Resolution Delta Search

The exact oracle should support a staged \(\Delta\)-search:

```text
1. Coarse Delta grid over the full allowed interval.
2. Identify the lowest free-energy Delta cell for each q.
3. If Delta_opt is close to zero or if neighboring Delta values are nearly degenerate, build a narrower local Delta interval.
4. Rescan with a finer Delta grid.
5. Optionally fit a local quadratic interpolation of free energy versus Delta
   to estimate a smoother Delta_opt.
```

Recommended metadata:

```text
Delta_min
Delta_max
n_delta_coarse
n_delta_refined
Delta_opt
Delta_refinement_level
free_energy_gap_to_normal
positive_delta_gap
```

For active learning, the important point is that boundary labels should depend
on the refined \(\Delta_{\mathrm{opt}}\), not on a coarse-grid artifact.

For normal candidates with \(\Delta_{\mathrm{opt}}=0\), the exact oracle should
not classify the point as ambiguous only because the free-energy gain relative
to the \(\Delta=0\) baseline is zero. It should also compute the best
strictly-positive-\(\Delta\) free-energy gap:

```text
positive_delta_gap =
    min_{Delta >= DELTA_EPS} F(Delta, q) - F(Delta = 0, q)
```

If `positive_delta_gap` is clearly positive, the point is a trusted normal
point. If it is near zero, the normal/SC label remains ambiguous. If it is
negative, the positive-\(\Delta\) state should be adopted and refined.

### 6.3 Finite-Resolution Normal/SC Boundary Band

The active-learning oracle should distinguish a numerical failure from a
physically unresolved boundary band. If a point satisfies

```text
Delta_opt = 0
positive_delta_gap >= 0
positive_delta_gap <= positive_delta_gap_tol
```

then the exact calculation has not found a positive-\(\Delta\) state with a
resolvable condensation-energy gain. Within the chosen physical/numerical
energy resolution, this point should be interpreted as normal-side or
normal/SC boundary-band data rather than as an exact-oracle failure.

Similarly, if a positive-\(\Delta\) solution exists but

```text
abs(free_energy_gap_to_normal) <= free_energy_ambiguity_tol
```

then the point lies inside the finite-resolution normal/SC boundary band. It
should not be used as evidence for a robust superconducting phase unless the
free-energy gain is negative by more than the adopted tolerance.

Operational rule:

```text
SC is accepted only when the superconducting free-energy gain is lower than
the normal state by more than the chosen tolerance.

If the gain is positive or below resolution, the point is treated as normal
side or boundary-band normal for phase-boundary construction, with metadata
preserved.
```

This convention avoids spending many active-learning iterations trying to
resolve condensation-energy differences below the accuracy scale relevant for
the present phase diagram. The metadata should still record
`positive_delta_gap`, `free_energy_gap_to_normal`, and the boundary-band status
so that future stricter studies can revisit these points.

## 7. Active-Learning Objective

The active learner should answer the question:

```text
Where should the next exact BdG calculations be run so that the phase boundary
is refined fastest per GPU-hour?
```

The warm-start exact dataset should be used first. Starting online from no data
is inefficient because uncertainty is initially high almost everywhere.

The active-learning loop is

```text
existing exact npz
    -> flatten dataset
    -> train regression surrogate and phase classifier
    -> score dense candidate grid
    -> select uncertain / boundary-like / under-resolved points
    -> partition selected points for H100 jobs
    -> run exact BdG oracle on shards
    -> merge exact shards
    -> append corrected exact points
    -> retrain
    -> repeat until boundary convergence
```

## 9. Surrogate and Classifier Models

Baseline input:

$$
X = [k_B T/t,\; J_A/t].
$$

Regression targets:

$$
Y_{\mathrm{reg}} =
[\Delta_{\mathrm{opt}}, q_{\mathrm{opt}}, \eta, I_c^+, I_c^-].
$$

Classification targets:

```text
normal / uniform_SC / FFLO
eta_pos / eta_neg / eta_zero
strong_diode / weak_diode
```

The current implementation uses small MLP ensembles.  The classifier
uncertainty combines normalized entropy and top-two margin uncertainty:

$$
U_{\mathrm{cls,mix}}(x)
= w_{\mathrm{ent}}H_{\mathrm{cls}}(x)
+ w_{\mathrm{mar}}U_{\mathrm{margin}}(x).
$$

The regression ensemble records channel-resolved uncertainty:

$$
\left(
U_{\Delta}, U_q, U_{\eta}, U_{I_c^+}, U_{I_c^-}
\right)(x).
$$

The phase-facing regression uncertainty uses the \(\Delta\) and \(q\)
channels, while response uncertainty is reported separately.

Recommended validation policy:

```text
hold out 15% of warm-start exact points
stratify by phase label when possible
report RMSE for continuous targets
report classification accuracy and boundary F1
```

The model should treat high-\(J_A\) points outside the warm-start range as
extrapolation. Candidate scores there must be interpreted conservatively and
confirmed by exact BdG calls with adaptive \(q\)-window checks.

## 10. Candidate Grid and Physics Mask

Candidate points are generated on a dense grid in \((kT, J_A)\), not only on the
existing exact grid.

Baseline candidate domain:

```text
kT in [0.0, 0.56]
JA in [0.0, 2.12]
```

Physics masks:

```text
1. remove all kT < 0;
2. prioritize the warm-start domain kT <= 0.5 and JA <= 1.2;
3. allow JA > 1.2 only near the finite-temperature boundary or where
   uncertainty/acquisition remains high;
4. downweight candidates whose predicted q_opt is outside the currently safe
   q-window until an expanded-q exact calculation is scheduled;
5. avoid spending exact calls deep inside uniform regions unless needed for
   diversity or extrapolation control.
```

The finite-temperature analytic or prior boundary from
`finite_T_phase_diagram.m` should be used as a soft mask and plotting reference,
not as a substitute for exact labels.

## 11. Acquisition Function

The current active-learning acquisition separates the main thermodynamic
phase-boundary score from response diagnostics.  The score used for main
exact-call ranking is

$$
A_{0,\mathrm{main}}(x)
= A_{\mathrm{phase}}(x)
+ A_{\mathrm{numerical}}(x)
+ A_{\mathrm{explore}}(x).
$$

The phase part is

$$
\begin{aligned}
A_{\mathrm{phase}}(x) =
&1.0\,U_{\mathrm{cls,mix}}(x)
+0.6\,U_{\mathrm{reg,phase}}(x)
+1.0\,B_{\Delta,\mathrm{gated}}(x)\\
&+0.9\,B_{q,\mathrm{SC}}(x)
+0.5\,G_{\mathrm{phase}}(x).
\end{aligned}
$$

The numerical-risk and exploration parts are

$$
A_{\mathrm{numerical}}(x) = 0.4\,E_{q,\mathrm{SC}}(x),
\qquad
A_{\mathrm{explore}}(x) = 0.15\,E_{\mathrm{ext,uncertain}}(x).
$$

Here \(B_{q,\mathrm{SC}}\) and \(E_{q,\mathrm{SC}}\) are multiplied by the
predicted superconducting probability \(P_{\mathrm{SC}}\).  The extrapolation
term is multiplied by model uncertainty.

The \(\Delta\)-boundary term is additionally gated by normal/SC classifier
competition:

$$
\begin{aligned}
B_{\Delta,\mathrm{raw}}(x)
&=\exp\!\left[-\frac{|\Delta_{\mathrm{pred}}(x)-\Delta_\epsilon|}
{\Delta_{\mathrm{scale}}}\right],\\
U_{\mathrm{NS}}(x)&=4P_{\mathrm{normal}}(x)P_{\mathrm{SC}}(x),\\
B_{\Delta,\mathrm{gated}}(x)
&=B_{\Delta,\mathrm{raw}}(x)U_{\mathrm{NS}}(x).
\end{aligned}
$$

This suppresses false large \(\Delta\)-boundary scores in high-confidence
deep-normal regions where \(\Delta_{\mathrm{pred}}\approx 0\) only because
\(\Delta_\epsilon\) is small.  The raw and gated values are both diagnostics,
but \(A_{\mathrm{phase}}\) uses the gated value.

The response score

$$
A_{\mathrm{response}}(x)
=0.3\,B_{\eta,\mathrm{response}}(x)
+0.3\,G_{\eta,\mathrm{response}}(x)
+0.3\,U_{\mathrm{reg,response}}(x)
$$

is saved for diagnostics but does not enter the main ranking.

The following terms do not enter \(A_{0,\mathrm{main}}\):

```text
B_eta response-boundary proximity
diversity score as an additive term
Delta-refinement risk as an additive term
```

Candidate reuse and soft repulsion:

After the acquisition score is computed, dense-grid candidate selection
hard-excludes coordinates that already exist in the exact dataset after
rounding \((kT, J_A)\) to 4 decimal places.  Nearby non-identical candidates
are no longer rejected by a rigid distance radius.  Instead, their acquisition
score is multiplied by a soft observation-repulsion factor

$$
R_{\mathrm{obs}}(x)
=
r_{\mathrm{floor}}
+
(1-r_{\mathrm{floor}})
\left[
1-\exp\left(-\left(d_{\mathrm{obs}}(x)/\ell_{\mathrm{obs}}\right)^2\right)
\right],
$$

where \(d_{\mathrm{obs}}\) is the normalized distance to the nearest existing
exact point.

```text
d_existing =
sqrt(
    ((kT_candidate - kT_exact) / (kt_max - kt_min))^2
  + ((JA_candidate - JA_exact) / (ja_max - ja_min))^2
)
```

Within each selected batch, the same idea is applied as a batch-repulsion
factor:

$$
R_{\mathrm{batch}}(x;\mathcal{B})
=
\prod_{s\in\mathcal{B}}
\left[
b_{\mathrm{floor}}
+
(1-b_{\mathrm{floor}})
\left(
1-\exp\left(-\left(d(x,s)/\ell_{\mathrm{batch}}\right)^2\right)
\right)
\right].
$$

The corrected selection score is

$$
A_{\mathrm{select}}(x)
=A_{0,\mathrm{pool}}(x)R_{\mathrm{obs}}(x)R_{\mathrm{batch}}(x).
$$

In discovery mode, selected exact-call batches are sampled stochastically with
probability proportional to \(A_{\mathrm{select}}(x)^{\gamma}\), where
\(\gamma\) is the configured sampling power.  The default discovery schedule
anneals \(\gamma\) upward during the run so late-stage sampling is sharper than
early exploration.  In refinement mode, deterministic top-\(k\) selection may
be used for reproducible warm-start boundary refinement.  Geometric
boundary-bracket midpoint selection remains disabled. Extracted exact boundary
segments are diagnostics only.

Discovery mode constructs the high-information active pool from
\(A_{0,\mathrm{pool}}\).  The default pool score applies a soft penalty to
high-confidence, low-information phase-interior candidates:

$$
A_{0,\mathrm{pool}}(x)=
A_{0,\mathrm{main}}(x)P_{\mathrm{interior}}(x),
\qquad 0\le P_{\mathrm{interior}}(x)\le 1.
$$

The pool threshold uses the stricter maximum of the scheduled quantile
threshold and the relative-p95 threshold:

$$
A_{0,\mathrm{pool}}(x)\ge
\max\!\left[
Q_{q_{\mathrm{pool}}}(A_{0,\mathrm{pool}}),
\alpha_{95}Q_{0.95}(A_{0,\mathrm{pool}})
\right],
$$

with an additional cap on the admitted fraction of hard-unseen candidates.
This keeps stochasticity inside a score-defined high-information pool rather
than across the full rectangular candidate grid.

Boundary scores may use exponential forms:

```text
B_Delta_raw = exp(-abs(Delta_pred - DELTA_EPS) / delta_scale)
B_Delta_gated = B_Delta_raw * U_NS
B_q     = exp(-abs(abs(q_pred) - Q_EPS) / q_scale)
B_eta   = exp(-abs(eta_pred) / eta_scale)
```

After scoring, selected points are kept unique by grid index.  The batch
repulsion factor lowers the probability of selecting near-duplicate points in
the same iteration without imposing fixed regional quotas.

## 12. Autonomous Iteration Logic

Each active-learning iteration should be restartable and deterministic for a
fixed random seed.

Two run modes are supported:

```text
discovery:
    start from random exact seed points on the full rectangular candidate grid;
    do not use the warm-start exact phase diagram as the initial training set;
    do not use the finite-T prior candidate band.

refinement:
    start from an existing warm-start or resume dataset;
    optionally use a prior-band candidate domain for warm-start boundary
    refinement.
```

One iteration is

```text
1. Load the latest trusted exact dataset.
2. Train regression ensemble and phase classifier.
3. Build candidate grid and physics mask.
4. Predict observables and uncertainty on the candidate grid.
5. Compute \(A_{0,\mathrm{main}}\) and \(A_{\mathrm{select}}\).
6. Select a diverse set of top candidates.
7. Mark candidates requiring q-window expansion or Delta refinement.
8. Write selected_points_iterXXX.csv and shard files.
9. Submit or print H100 exact-oracle array command.
10. Run exact oracle on each shard.
11. For each point, perform q-window and Delta-refinement checks.
12. Save shard results with metadata and partial-progress safety.
13. Merge shards.
14. Reject, flag, or rerun failed / q-edge-hit / numerically ambiguous points.
15. Append clean exact results to dataset_iterXXX.npz/csv.
16. Retrain or advance to next iteration.
17. Generate figures and update the report.
```

The loop stops only when multiple criteria agree:

```text
1. phase-map change is small on the fixed monitor grid;
2. normal/SC boundary displacement is below tolerance;
3. uniform_SC/FFLO boundary displacement is below tolerance;
4. label-surprise rate is small after exact labels return;
5. exact-data coverage of the main thermodynamic boundaries is sufficient.
```

Current stop-controller policy:

```text
Soft acquisition repulsion means a candidate batch may remain available even
after the phase-boundary information has saturated. Therefore no-available
candidates is only an exceptional stop reason, not the main convergence rule.

Each completed exact-oracle iteration writes stop metrics based on:
    phase_map_change on a fixed monitor grid
    normal/SC boundary shift
    uniform_SC/FFLO boundary shift
    label_surprise_rate between predicted and exact phase labels
    selected_A0_ratio relative to the early-iteration acquisition baseline
    q_edge_trigger_rate
    rerun_required_rate
    boundary_coverage_p95 for the two main thermodynamic phase boundaries

Eta-zero response boundaries are excluded from the main stop rule. Topological
boundaries are also excluded until a pointwise topological exact oracle is
implemented.

Convergence requires at least four of the five main phase-map and boundary
conditions to pass for a configured patience window.  The selected-acquisition
ratio, q-edge rate, and rerun-required rate are diagnostics and cleanup
warnings; they do not block the main phase-boundary active-learning stop.
```

## 13. H100 / Supercomputer Execution Model

The supercomputer workflow must separate CPU-side model work from GPU-side exact
BdG work.

CPU-side job:

```text
build dataset
train models
score candidate grid
select points
write point shards
write metadata and suggested sbatch command
```

GPU H100 array jobs:

```text
read one shard
run exact BdG oracle on assigned points
perform q-window expansion if needed
perform Delta refinement near boundaries
write exact_shard_rankXXX_ofYYY.npz
write per-point status metadata
```

Postprocess job:

```text
check all shards
merge exact outputs
deduplicate points
append clean exact data
report failures or rerun list
generate plots and report
```

Use partition `NV_H100` on the GBU cluster. The code should be controlled by an
explicit Python path when conda activation is unreliable in SLURM:

```bash
export PYTHON_BIN=/public_hw/home/sci_bfu/.conda/envs/my_env/bin/python
```

Do not rely on `torch.cuda.is_available()` on login nodes. CUDA availability
should be checked inside the H100 job.

## 15. Numerical Ambiguity and Rerun Policy

An exact point should not be blindly appended if any of these occurs:

```text
q_opt is too close to q_min or q_max
Delta_opt is close to DELTA_EPS and was computed only on a coarse Delta grid
free-energy differences are below tolerance
eta or critical current is non-finite
phase label changes under small q/Delta refinement
```

However, normal/SC boundary-band points should not be treated as generic
failures. If `Delta_opt=0` and the best positive-\(\Delta\) state is not lower
than the normal state by more than the adopted tolerance, the point can be used
as a normal-side boundary datum with explicit boundary-band metadata.

Such points should be written to a rerun list:

```text
ML_Phase/active_runs/<run_id>/iterXXX/rerun_points.csv
```

The rerun list should include recommended corrections:

```text
expand q-window
increase n_q
refine Delta grid
increase n_delta
rerun with stricter tolerance
```

## 17. Validation Checks

Required checks:

```text
1. q = 0 limit agrees with the uniform BCS/TSC limit where applicable.
2. Delta = 0 points are labeled normal.
3. Increasing q resolution does not shift q_opt except near known ambiguous
   points, where refinement metadata must explain the shift.
4. Increasing Delta resolution does not qualitatively move the normal/SC
   boundary.
5. No plotted or candidate point has kT < 0.
6. Repeated active-learning runs with the same seed produce identical selected
   points before exact-oracle nondeterminism.
7. Merged H100 shards exactly match the selected point list after deduplication.
8. q-edge-hit points are corrected or excluded from trusted training data.
```

## 19. Scientific Narrative

The final paper/report narrative should be:

```text
We first compute a reliable exact BdG phase diagram on a broad grid. This gives
the global phase structure and a warm-start dataset. We then train an
uncertainty-aware surrogate model that predicts the order parameter, FFLO
momentum, diode efficiency, and phase label. The surrogate is used only to
choose where exact calculations are most valuable. New H100 BdG calculations
are concentrated near normal/SC, uniform/FFLO, eta-sign, strong-diode, and
high-JA q-sensitive boundaries. During exact evaluation, q windows and Delta
sampling are adaptively refined so that the active learner does not mistake
grid truncation or coarse Delta resolution for physical phase boundaries.
```
