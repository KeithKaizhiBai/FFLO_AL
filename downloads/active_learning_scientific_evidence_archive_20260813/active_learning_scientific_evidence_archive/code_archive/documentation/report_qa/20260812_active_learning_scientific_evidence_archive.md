# Active Learning Scientific Evidence Archive

## Purpose

The Windows-side project has been reduced to a curated scientific evidence archive for independent Mac-side manuscript work, figure regeneration, data audit, and result verification. The archive preserves computational evidence without importing manuscript LangGraph, claim-registry, or AI-writing workflow state.

## Scientific Scope

- Stage I: 2D thermodynamic active-learning baseline.
- Stage II: robust exact-oracle optimization, frozen `dataset_iter035`, trusted/hard-risk semantics, and publication boundary audit.
- Stage III: final topology dataset, Pfaffian/bulk-gap validation, cFFLO/tFFLO labels, and converged 2D topology-boundary audit.
- Stage IV: final 3D dataset, fixed-mu slices, selected-point history, phase/topology maps, and non-convergence diagnostics.
- Stage V: v1/v2/v2-tail/v3 datasets, acquisition/reward/proposal-source evidence, matched audits, and v4 implementation/package provenance.
- Stage VI: no independent formal world-model experiment was found.

## Integrity

The curated files were copied byte-for-byte and checked against source SHA256 values. The final directory checksum file revalidated all listed files with zero failures, and the ZIP CRC test passed. The transfer ZIP SHA256 is recorded in:

```text
active_learning_scientific_evidence_archive.zip.sha256
```

## Caveats

- `finite_T_phase_diagram.m` is not present in the current Windows repository.
- Stage V-v4 final production data and formal return audit are not present locally.
- Archival inclusion does not promote provisional labels or report-only smooth surfaces to definitive physical boundaries.
- Stage IV and Stage V-v1/v2/v3 retain their original non-converged/prototype decisions.
