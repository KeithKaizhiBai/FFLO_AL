# PPT Generation Template

Use this template when Codex should create or update a presentation.

## Presentation Goal

State the target audience, talk length, and main scientific message.

## Source Material

List reports, papers, figures, tables, and notes to use.

## Slide Requirements

```text
title slide:
motivation:
methods:
results:
limitations:
next steps:
backup:
```

## Style Constraints

Specify fonts, aspect ratio, color rules, figure style, and whether the output
must be editable PowerPoint.

## Outputs

```text
deck.pptx
deck.pdf
figures/
speaker_notes.md
```

## QA

Render or inspect slides for clipped text, unreadable figures, broken formulas,
and inconsistent labels.
