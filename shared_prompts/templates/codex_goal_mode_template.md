# Codex Goal Mode Template

Use this template for a long autonomous Codex task.

## Goal

State the exact objective and expected final deliverables.

## Inputs

List source files, datasets, reports, logs, or remote paths Codex should read.

## Constraints

List what Codex must not change, rerun, delete, submit, or reinterpret.

## Required Outputs

List reports, tables, figures, scripts, manifests, or documentation updates.

## Validation

List commands, numerical checks, rendering checks, or consistency checks.

## Final Response

List the exact items Codex should report back at the end.
